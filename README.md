## Аналитика нефти, сырья и волокна

В кабинете добавлен раздел «Аналитика» (`team/#analytics`). По умолчанию включена **демонстрация**: все её нефтяные, сырьевые и поставщицкие числовые ряды вымышлены, шесть поставщиков названы условно. Демо не записывает котировки в Supabase. SVG-экспорт содержит пометку ДЕМО. Режим «Мои котировки» использует только записи, доступные текущему пользователю по существующим RLS-правам; при выходе графики, имена поставщиков и выбранные ряды очищаются.

Графики автоматически строятся по одному виду волокна и выбранным поставщикам (до 8). Цены CNY переводятся в USD по курсам каждой котировки; для стоимости на одном складе выбирается конкретный маршрут, CPT не добавляет фрахт повторно. В расчёт берутся котировки с текущими характеристиками карточки. Временные пробелы не интерполируются, индекс 100 использует общую фактическую базовую неделю. FOB/FCA и CPT не считаются одной ценовой базой; сравнение отклонения цены требует подтверждения характеристик и совпадения условий, либо общего склада в режиме доставленной стоимости.

Сценарий нефть → индекс сырья → волокно — линейная модель недельных изменений с заданными лагами. Выдача оценки требует 28 пар и R² >= 0,15, проверка выполняется отдельно на последних 6 неделях. Это условный сценарий реакции, не гарантированный прогноз и не доказательство завышения цены. Вес PTA/MEG — параметр индекса, не рецептура PET. Для вискозы используется растворимая целлюлоза, без прямого нефтяного прогнозирования. Справочник состава даёт типовые схемы с источниками производителей; не подменяет паспорт марки.

**Реальная нефть** в режиме собственных котировок: `docs/market/oil.json`, публичный дневной ряд U.S. EIA через FRED DCOILBRENTEU, агрегированный в среднее завершённой календарной недели (не меньше трёх наблюдений). При первоначальной загрузке последнее использованное наблюдение — 2026-11-06. Источник: https://fred.stlouisfed.org/series/DCOILBRENTEU . Данные могут отставать и пересматриваться, дата последнего наблюдения показана отдельно. Не путать Brent spot с фьючерсной ценой.

`.github/workflows/oil-weekly.yml` проверяет источник по пятницам в 18:17 UTC и запускает переиспользуемую публикацию Pages с точным SHA нового коммита. Расписание GitHub может задерживаться. При ошибке загрузки прежний JSON сохраняется; просроченные данные помечаются на сайте. Публикуются только открытые нефтяные данные, а не коммерческие предложения или подписные обзоры.

PTA/MEG, целлюлоза и котировки PSF/VSF из реального внешнего источника пока не подключены: пользователь предоставит его позже. До подключения можно импортировать CSV `series,date,value,unit,source` (PTA/MEG/PULP/PSF/VSF, USD/kg или USD/t). Обзор остаётся в localStorage данного браузера и не синхронизируется с отделом. Нет реальных ориентиров или достаточной истории — нет числовой прогнозной оценки. Новая миграция базы для этого раздела не требуется.

Проверки: `node tests/analytics-model.test.mjs`, `node tests/analytics-ui.test.mjs`, `node tests/oil-data.test.mjs` и существующие тесты кабинета. Реальные подписные источники и точность модели на ваших данных ещё не проверены. Браузерный визуальный просмотр недоступен в текущем окружении; функциональность проверена DOM-тестами.
