# @fiberanalytics_bot — первая версия

Python 3.12+, внешние библиотеки не нужны. Работает через long polling; домен и входящий порт не нужны. Нужен постоянно работающий сервер с исходящим HTTPS-доступом к api.telegram.org.

## Что готово

Личный доступ по Telegram ID, пошаговый калькулятор, пять складов, USD/CNY, смешанный USD/RUB фрахт, сценарии +10/+20% доставки FCA/FOB. CPT не добавляет доставку второй раз. SQLite сохраняет незавершённый ввод после перезапуска. Автоматических котировок, истории цен, рыночных прогнозов и импорта фотографий пока нет. Результат — товар и введённая доставка, а не полная таможенная себестоимость.

## Запуск с телефона

1. Выберите хостинг с постоянным Python worker, например Render Background Worker (платная услуга). Обычный статический сайт не подходит. Создайте приватный GitHub-репозиторий и загрузите файлы этой папки без токена.
2. Создайте worker из репозитория. Команда запуска: `python bot.py`. Если сервис требует build command: `python -m compileall -q .`. Выберите Python 3.12 или новее.
3. В Secret/Environment настройках worker добавьте `TELEGRAM_BOT_TOKEN` — токен от BotFather. Не добавляйте его в код, GitHub или чат.
4. Добавьте `ALLOWED_USER_IDS` — числовой Telegram ID администратора. Если ID неизвестен, временно поставьте `1`, запустите worker, отправьте своему боту `/id`, затем замените `1` полученным ID и перезапустите. Для коллег добавляйте ID через запятую. Команда `/id` доступна без доступа к расчётам.
5. Подключите постоянный диск в `/data` и задайте `DATABASE_PATH=/data/bot.sqlite3`. Без постоянного диска ввод и offset могут теряться при пересоздании worker. Запускайте только один экземпляр worker.
6. Откройте https://t.me/fiberanalytics_bot и отправьте `/start`, затем `/calculate`.

Хостинг может менять тарифы и интерфейс; проверьте стоимость перед созданием платного worker. Этот проект ещё не размещён на хостинге и не подключён к Telegram. Не запускайте вторую копию одновременно. Если уже установлен webhook, приложение остановится: сначала проверьте, какое приложение его использует.

## Проверка

`python -m unittest -v`

Пример FCA: 0,85 USD/кг, 22 000 кг, фрахт 2 250 USD, USD=100, CNY=14 → 95,23 ₽/кг. Курсы здесь условные. Для CPT 1,05 USD/кг при USD=100 → 105 ₽/кг; включённый фрахт повторно не добавляется.

Цены на фото не импортированы: даты не подтверждены, часть названий складов обрезана. При вводе китайской логистики уточняйте валюту, тип контейнера, срок ставки, состав услуг и последнюю милю. Для CPT выбранный склад должен соответствовать согласованному пункту доставки. Для других стран уточняйте базис отдельно.
